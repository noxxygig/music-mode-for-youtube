# Chrome Web Store – Listing

**Name:** Music Mode for YouTube™
**Summary (max 132):** Turn YouTube into a distraction-free music player: cover art instead of video, optional data saver.
**Category:** Entertainment (or Productivity)

**Description**
Music Mode for YouTube™ hides the video and shows the cover art and title instead – ideal when you only listen.
• One-click toggle in the player controls or Alt+M
• Optional data saver (lowest video quality while Music Mode is on)
• Optionally hides recommendations and comments
• No account, no tracking, no ads

Not affiliated with, endorsed by or sponsored by YouTube or Google. YouTube is a trademark of Google LLC.

**Single purpose:** Provide an audio-focused viewing mode on youtube.com.

**Permission justification**
- `storage`: saves the user's settings (Music Mode on/off, data saver, hide recommendations).
- Content script on `https://www.youtube.com/*`: needed to hide the video and show the cover art.

**Data usage:** No personal data collected, stored remotely, sold or transferred. Settings are stored only via chrome.storage.sync.

**Privacy policy:** Required field – short page stating the above (host e.g. on GitHub Pages).
